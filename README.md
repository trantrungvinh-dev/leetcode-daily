# LeetCode Daily Practice

This repository contains my daily solutions to LeetCode problems using JavaScript.  
Each folder corresponds to a specific problem, including the solution and unit tests using Jest.

## 📌 Structure

- `001-two-sum/` - Problem #1: Two Sum
- `002-add-two-numbers/` - Problem #2: Add Two Numbers
- `...`

## 📅 Goal

Solve at least one LeetCode problem every day and keep track of progress here.

## 🧪 Testing

All solutions are written with test cases using [Jest](https://jestjs.io/).  
Run tests with:

```bash
pnpm install
pnpm test
```
